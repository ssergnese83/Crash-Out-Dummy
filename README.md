# Crash-Out-Dummy

## Controls

### Keyboard and Mouse
- WASD     = Movement
- Shift    = Sprint
- Mouse    = Camera
- Space    = Jump
- C        = Slide/Interact
- TAB      = View Control Scheme

## Debug Shortcuts
- N = Next Level
- T = Reset to Level 1
- F = Super Speed
- R = Initiate Self Kill
- M = Clear Dead Bodies
- / = Reset Tutorial

## Coding Practice
- Unreal Engine 5.5.4
- No spaces in folder and file names
